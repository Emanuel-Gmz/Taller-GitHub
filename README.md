Taller de Git y GitHub 
¡Bienvenidos al repositorio oficial del taller de Git y GitHub! 🚀

Este espacio fue creado para que cada asistente pueda practicar el flujo de trabajo colaborativo real: clonar, crear ramas, realizar cambios, commitear y hacer push de su trabajo.

📋 Objetivos del Taller
Entender por qué Git y GitHub son indispensables en el desarrollo de software profesional.

* Aprender a configurar Git localmente.

* Dominar el flujo de trabajo básico:

* Clonar un repositorio.

* Crear ramas (branches) para trabajar de forma aislada.

* Hacer commits para guardar cambios.

* Hacer push para subir tu trabajo.

* Realizar Pull Requests para integrar código en equipo.
